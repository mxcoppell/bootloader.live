# Goal

This post is the **canonical reference** for the HTML blog format. It is not a substantive content post — it exists to demonstrate every supported element so future HTML posts can copy-paste from it.

## Scope

- Lead paragraph (cold open archetype)
- Section badge component
- Track A illustration (PNG)
- Track B illustration (PNG)
- Track C interactive SVG — hover-reveal
- Track C interactive SVG — step-through
- Track C interactive SVG — toggle-view
- Styled callout
- Code block with syntax highlighting
- Table
- References section

## Non-goals

- Substantive research or factual claims that need ongoing verification
- A specific tool recommendation
- A timely opinion (this post is intended to live forever as a reference)

## Audience

Authors writing future HTML blog posts. The post explains, in 600 words, when each illustration track is appropriate.
